## 22. Why four bits is enough

The engine's /metrics endpoint reports tensorfold:device_memory_bytes = 111,515,771,428 bytes on 2026-10-31, which is 111.5 GB of unified memory shared by CPU and GPU. NVIDIA's DGX Spark hardware guide lists 273 GB/s of LPDDR5X bandwidth for that shared pool. The KV pool is 262,144 positions, set by CONTEXT=262144 in scripts/local.sh. The live container has PARALLEL=4 and TF_DS_STREAMS=4, so four streams share the pool. Each stream's equal share is 262,144/4 = 65,536 positions. Admission reserves the default reply budget of 32,768 tokens (MAX_TOKENS=32768), the decode round batch width ROUND_ROWS=16, and two guard positions. The per-stream ceiling is 65,536 - 32,768 - 16 - 2 = 32,750 tokens. The 18 positions beyond the reply budget are the admission overhead. Raising the pool to the native 1,048,576 positions gives 1,048,576/4 - 32,768 - 16 - 2 = 229,358 tokens per stream.

The memory cost of that raise is 0.68 GiB per rank. scripts/config.sh gives 0.9 GiB per 1,048,576 positions per rank. The increment from 262,144 to 1,048,576 is 0.75 of the full window, so 0.9 * 0.75 = 0.675 GiB, rounded to 0.68 GiB per rank. A rank is one process holding a shard of the model and cache. The cited metrics do not give the rank count, so the per-rank figure is the unit to use; multiply by the number of ranks for the deployment total. The same config implies 0.9 GiB / 1,048,576 = 921.6 bytes per position per rank. With 16-bit keys and values, each element is 2 bytes and there are two tensors, so 921.6/4 = 230.4 stored elements per position per rank per tensor (460.8 total across the K and V tensors). The layer, KV-head and head-dimension product must equal that per-tensor effective count At four bits, each element is half a byte, so the same bytes hold four times the positions. The current 262,144-position pool would become 1,048,576 positions, and the per-stream ceiling would become 229,358.

A transformer block takes a residual stream, normalizes it, runs self-attention, adds the attention output back, normalizes again, runs a feed-forward network, and adds that output. Attention forms queries, keys and values from the stream. Each output position is a softmax-weighted sum of value vectors. Layer normalization subtracts the mean across channels, divides by the standard deviation, then applies a learned scale and bias. Quantization maps a real value to a finite grid with a scale and sometimes a zero-point. Symmetric quantization uses a signed grid over [-m,m]; with an even number of levels, zero falls between two levels. Asymmetric quantization adds a zero-point so zero is exactly representable and the grid can cover [min,max]. Clipping sets values beyond m to ±m. Group size is the number of contiguous weights sharing a scale; smaller groups reduce outlier contamination and cost more scale bits.

Take a symmetric four-bit group with m=1.0. Sixteen signed levels over [-1,1] have 15 intervals, so the step is 2/15 = 0.1333. The levels are -1, -0.8667, -0.7333, .. 1. A weight of 0.41 rounds to 0.4667, an error of +0.0567, which is less than half a step, 0.0667.

Now the dot product. A linear layer computes y = sum_i w_i x_i over N terms. Quantize each w_i to q_i and let e_i = q_i - w_i. The output error is sum_i e_i x_i. Take N=4,096, a half-step of 0.067, and an input RMS of 0.5. Each term. If every e_i had the same sign and every x_i the same sign, the total would be 4,096 * 0.0335 = 137.2. If the e_i are independent with zero mean, the variance is sum_i Var(e_i x_i) plus covariance terms. With zero covariance, the standard deviation is at most sqrt(4,096) * 0.0335 = 64 * 0.0335 = 2.14; using the actual per-term std for uniform rounding, (step/√12)·x_rms ≈ 0.0385·0.5 ≈ 0.0192, gives ≈ 1.23. The ratio between the linear and quadrature totals is 64, the square root of N. That is the effect of independence.

The quadrature step requires cov(e_i x_i, e_j x_j) to be near zero. Rounding error e_i is a deterministic function of the fractional part of w_i/step. For fixed rounding errors, Cov(e_i x_i, e_j x_j) = e_i e_j Cov(x_i, x_j), so the covariance is small only when either the rounding-error product is small or the corresponding inputs are uncorrelated; correlated inputs can keep it nonzero regardless of fractional-part/sign alignment GPTQ (Frantar, Ashkboos, Hoefler and Alistarh, 2022) uses a second-order approximation of the layer-wise reconstruction error to update the remaining weights after each rounding, so later weights compensate for earlier quantization errors. Its objective is ||WX - ŴX||^2 = (W-Ŵ) H (W-Ŵ)^T with H = XX^T. The Hessian tells you which directions in weight space change the layer output little. GPTQ rounds weights in an order that lets later weights compensate earlier errors, pushing error into low-curvature directions. AWQ (Lin and colleagues, 2023) scales weight channels with large activation magnitude before quantization so those channels get a finer effective quantization step, at the cost of reduced clipping headroom. Both methods are ways to handle correlated inputs and weights; neither makes the independence assumption true in general.

The residual stream adds another layer. Each block adds its output to the stream, so the final logits are a sum of the embedding contribution and every block's contribution. If the weight errors in different blocks are independent, their contributions add in quadrature. Layer normalization sits between the stream and each block. Let x be the stream, μ its mean, σ its standard deviation, and δ a perturbation. The normalized vector is z = (x-μ)/σ. To first order, the perturbation in z is Δz = (δ - mean δ)/σ - z * (mean(z δ)/σ). The first term removes the mean shift. The second removes the component along z that would change the variance. The remaining perturbation is orthogonal to the constant vector and to z, with norm at most ||δ||/σ. Layer normalization does not make δ vanish. It projects out two directions and rescales by 1/σ. If σ is small, the perturbation can grow. Layer normalization normalizes the input to each block to a fixed scale before the learned scale and bias. The perturbation entering the next block is measured against that fixed scale, so it does not compound multiplicatively with the stream's magnitude. The residual connection adds block outputs; it does not multiply them.

The bandwidth argument needs a roofline check. At batch one, decoding reads the weight matrix once per token and does little arithmetic per byte. The measured 59.1 tok/s at 273 GB/s implies 273e9 / 59.1 = 4.62e9 bytes per token, or 4.62 GB of bandwidth-equivalent traffic. Four-bit weights are half the bytes of eight-bit and a quarter of sixteen-bit, so the read time falls in proportion if nothing else binds. At concurrency four, if the four streams were fused into one weight read and KV traffic were negligible, the ceiling would be 4 * 59.1 = 236.4 tok/s; more generally, with KV reads scaling with batch, the ceiling is 4·BW/(W+4KV), below 4×. The measured 106.2 tok/s is 1.80x, so the engine gets partial reuse. The gap comes from KV traffic, attention math, and batch formation. The roofline moves from memory-bound toward compute-bound but does not reach the ideal 4x.

Four is close to a floor for weights. At four bits the step is m/7. At three bits it is m/3. At two bits it is m If the largest weight in a group is about 3σ, the half-step at four bits is 0.2σ, at three bits 0.43σ, at two bits 1σ. Once the half-step approaches σ, rounding stops being a perturbation and starts being a different function. The exact quality depends on group size and model, so four is an empirical default rather than a theorem. The failure mode at four bits lives in the tail. Suppose a group has weights 0.1, 0.2, 0.3 and 4.0. The scale is m=4.0, the step is 2*4/15 = 0.533. The first three weights all round to 0.2667; the outlier sets the grid and the small weights collapse to one level. If the group is split so 4.0 is alone, the other three get m=0.3, step 0.04, and they are represented with much finer resolution. Group quantization gives separate scales to small blocks so one outlier contaminates only its own block.

Activations have a different shape. LLM.int8() (Dettmers and colleagues, 2022) reported that a small set of hidden dimensions carries much larger magnitudes than the rest, and that the same dimensions recur across tokens in the batches they studied. A single per-tensor scale set by an outlier makes ordinary channels coarse. If an ordinary channel's values are mostly positive and the grid step is larger than their spread, they all round to the same level. The error is level minus value, with the same sign across tokens. That is a bias. Averaging over more tokens reduces the variance of independent noise and does nothing to a bias. The correlation comes from the shared scale and from the channel's own distribution, not from a claim that every token in every sequence is identical.

SmoothQuant (Xiao, Lin, Seznec, Wu, Demouth and Han, 2022) moves the difficulty from activations to weights. Take activation channel j with values around 10 and weight column j with values around 0.1. The product is 1. Scale the activation down by s=0.1 and the weight up by 1/s=10. The activation becomes 1, the weight becomes 1, and the product is still 1. The activation dynamic range is reduced by 10, the weight range is increased by 10, and the product is unchanged. Choose s to balance activation and weight quantization error; equalizing the two ranges is the special case α=0.5, but α is tuned because over-migrating outliers into weights can hurt 4-bit weight accuracy Per-token scaling gives each token's activation vector its own scale, so a token with a large outlier does not set the step for other tokens. That removes token-to-token correlation from the scale. Channels within a token can still be correlated. Four-bit activations need outlier handling and per-token scaling; the methods are not interchangeable with weight-only quantization.

Keys and values fail differently. The output of an attention head is a weighted average of value vectors whose weights sum to one. If value errors e_j were independent across positions, the error variance would be sum_j a_j^2 Var(e_j), and the errors would average in quadrature. Positions are correlated through attention and context, so e_j can covary. Per-token value quantization removes the shared-scale source of correlation, not all of it. Keys are compared against queries and passed through a softmax. For two logits 0 and 0, p=(0.5,0.5). Perturb the first logit by 0.1. The new p1 is e^0.1/(e^0.1+1) = 0.525, a change of 0.025. The first-order formula is p1(1-p1)Δ = 0.5*0.5*0.1 = 0.025. A key error changes an attention weight by p(1-p)Δ, with the largest effect near p=0.5. Keys also carry channel-outlier structure, with certain dimensions consistently large across positions. KIVI (Liu, Yuan, Jin, Zhong, Xu, Braverman, Chen and Hu, 2024) quantizes keys per-channel and values per-token. The axis you can average over decides the format. For values it is the token axis. For keys it is the channel axis.
