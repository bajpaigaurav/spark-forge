Glossary

The load-bearing terms, one sentence each, pointing at the chapter that defines them.

amax
The largest absolute value in a tensor, used to pick the scaling factor that maps it into a narrow format like fp8. ch. 20
arithmetic intensity
The number of floating-point operations a kernel performs per byte of memory it moves, which decides whether it is limited by compute or by bandwidth. ch. 29
attention
A layer that lets each token read a weighted sum of value vectors from earlier positions, with the weights set by how well its query matches their keys. ch. 05
attention sink
A position that absorbs probability mass a head has nowhere better to put, which in practice is usually the first token of the sequence. ch. 07
bf16
A sixteen-bit float with eight exponent bits and seven mantissa bits, so it keeps fp32's range but loses resolution. ch. 20
BPE
Byte-pair encoding: start from single bytes and repeatedly merge the most frequent adjacent pair into a new symbol, which is how token vocabularies are built. ch. 01
continuous batching
Admitting and retiring requests at every decode step rather than waiting for a whole batch to finish, so a freed slot is filled immediately. ch. 27
decode
The phase that emits one token per forward pass, reading every weight once per token and therefore limited by memory bandwidth. ch. 26
embedding
A table lookup that turns a token id into a vector, so the model's first operation is a memory read rather than arithmetic on the id. ch. 02
Flash Attention
An exact attention kernel that processes score tiles in shared memory and never materializes the full n-by-n matrix. ch. 14
fp32
The thirty-two-bit float: eight exponent bits for range and twenty-three mantissa bits for resolution, and the format mixed-precision training accumulates in. ch. 20
fp8
An eight-bit float format, e4m3 or e5m2, that needs a per-tensor scale because its exponent range is far too small on its own. ch. 20
GELU
An activation that multiplies its input by the standard normal CDF, attenuating small negative values instead of zeroing them the way ReLU does. ch. 17
group size
The number of contiguous weights that share one quantization scale; smaller groups confine outlier damage and cost extra scale bits. ch. 22
grouped-query attention
A middle setting between full multi-head and multi-query attention where groups of query heads share one key-value head, cutting the KV cache by the group count. ch. 11
KV cache
The stored keys and values for every position already processed, so decode does not recompute them for each new token. ch. 10
LayerNorm
Normalization that subtracts the mean across a token's features and divides by their standard deviation, then applies a learned scale and shift. ch. 18
logits
The raw, unbounded scores the output projection gives each vocabulary entry before softmax turns them into probabilities. ch. 23
mixture of experts
A block with many parallel expert feed-forward networks where a small router sends each token through only a couple of them. ch. 19
MLA
Multi-head latent attention: cache a single low-rank latent per token per layer and reconstruct each head's keys and values from it. ch. 11
multi-head attention
Running several independent attention operations in parallel over the same positions so each head can express a different relation. ch. 06
multi-query attention
Attention where every query head shares one key-value head, which shrinks the KV cache by the head count at some cost in quality. ch. 11
outlier
A value far from the rest of its tensor that forces a wider scale and so coarsens the step size for everything around it. ch. 21
PagedAttention
Serving the KV cache in fixed-size blocks addressed through a per-request block table, borrowing virtual memory's answer to fragmentation. ch. 12
permutation equivariant
A property of unmasked attention: shuffle the input tokens and the output is the same set of vectors in the shuffled order. ch. 08
pipeline parallelism
Splitting a model by layer across devices, so activations pass between stages and devices sit idle during the pipeline's fill and drain. ch. 28
positional encoding
Whatever injects order into attention, either a fixed sinusoidal vector added to each embedding or an angle that rotates queries and keys. ch. 08
prefill
The phase that runs the whole prompt through the model in one pass, doing matrix-matrix work that is limited by compute rather than bandwidth. ch. 26
prefix caching
Keeping the KV blocks for a token prefix so a later request that starts the same way reuses them instead of prefilling again. ch. 13
quadratic wall
The cost of full attention, which compares every token against every other, so the pair count grows with the square of the sequence length. ch. 09
quantization
Mapping a tensor onto a coarser grid of fewer bits, with a scale that trades resolution for a smaller footprint. ch. 21
residual stream
The single vector that every block reads from and adds to, carrying the representation forward from the first layer to the last. ch. 03
RMSNorm
Normalization that divides by the root mean square of the features and skips the mean subtraction, so it costs one reduction less than LayerNorm. ch. 18
roofline
A model that plots attainable performance against arithmetic intensity, so every workload lands under either the compute roof or the bandwidth roof. ch. 29
significand
The significant digits of a float, stored as an implicit leading one plus a fraction, whose width sets the resolution rather than the range. ch. 20
sliding window
A sparse attention pattern where each token attends only to a fixed number of preceding positions, making cost linear in context length. ch. 15
softmax
The function that exponentiates a row of scores and divides by their sum, turning unbounded affinities into shares that add to one. ch. 07
speculative decoding
A cheap drafter proposes several tokens and the target model verifies them all in one pass, so accepted tokens cost one forward pass each instead of a full step. ch. 25
SwiGLU
A gated feed-forward activation that multiplies the expanded vector by a second projection before contracting, and widens the hidden layer by about a third. ch. 17
temperature
A divisor applied to the logits before softmax that flattens the distribution above one and sharpens it below one. ch. 24
tensor parallelism
Splitting each weight matrix across devices so every device stays busy, paying for it with collectives inside every block. ch. 28
throughput
The aggregate rate of tokens produced across all active streams, which rises with batch size as weight reads are amortized. ch. 27
token
A piece of text the tokenizer assigns an integer id to, which is the only form of input a language model ever sees. ch. 01
top-k
Truncation that keeps the k highest-scoring candidates and renormalizes, so the tail it admits is a fixed count regardless of distribution shape. ch. 24
top-p
Nucleus sampling: keep the smallest set of candidates whose cumulative probability reaches p, so the truncation width adapts to the distribution. ch. 24
TTFT
Time to first token, the delay between a request arriving and the first output token, which tracks prefill more than anything else. ch. 26
