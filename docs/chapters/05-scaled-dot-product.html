II. Attention · Chapter 05

The 2017 move: drop the recurrence

Scaled dot-product attention is a differentiable lookup table, and the scaling factor is there for a reason you can compute on paper.

Assumes 04.

In 2017, Vaswani et al. published "Attention Is All You Need." The paper was about machine translation, but its argument was larger. A sequence model does not need recurrence. Recurrent networks process tokens one at a time. To compute the hidden state at position t, you need the hidden state at t-1. That sequential dependency makes training on long sequences slow, and it forces gradients to travel through every step. The 2017 paper replaced the recurrence with attention, and attention has no such dependency. Every position can be computed at once.

Four pieces of background carry the rest of this chapter. A matrix multiply is a sum over an index, so an n-by-d matrix times a d-by-m matrix costs n m d multiply-adds. A multiply-add counts as two floating-point operations, which is the convention behind every FLOP figure below. The derivative of a softmax share a_ij with respect to a score s_ik is a_ij times (1 if j equals k, else 0, minus a_ik). And a GPU wants thousands of independent arithmetic operations in flight at once. An operation that must wait on its own previous step leaves most of those cores idle.

Start with one token. In a transformer layer each token is represented by a vector x of length d_model. That vector is the residual stream. It runs the length of the network, and every sublayer reads from it and writes an addition back into it. The layer learns three weight matrices, W_Q, W_K and W_V, each of shape d_model by d_k. It multiplies x by each, giving q = x W_Q, k = x W_K and v = x W_V. These are the query, key and value for that token. The same three matrices apply to every token, so a sequence of n tokens yields n queries, n keys and n values.

A block wraps attention in two pieces. The first is a residual connection. The sublayer's output is added to x rather than replacing it, so the gradient has a direct path back through the addition and information from earlier layers survives. The second is layer normalization, which rescales the vector to zero mean and unit variance across its d_model components, then applies a learned scale and shift. The original 2017 paper placed the norm after the residual addition, computing LayerNorm(x + Sublayer(x)); most later models moved it before the sublayer. After attention comes a feed-forward network, two linear layers with a nonlinearity between them and an inner width typically four times d_model. It is applied to each position independently. Attention mixes information across positions; the feed-forward layer transforms each position on its own.

Attention itself is permutation equivariant. Shuffle the tokens and the set of dot products is unchanged, so the output is the same set of vectors in a different order. Order has to be injected. The 2017 paper added a fixed sinusoidal vector to each token embedding, with component 2i set to sin(pos / 10000^(2i/d_model)) and component 2i+1 set to cos(pos / 10000^(2i/d_model)). Different positions get different vectors, and the pair at any position is a fixed rotation of the pair at any other, so the model can learn to read relative offsets from the dot products. Later models learned the position vectors instead, and rotary position embedding (Su et al. 2021) rotates q and k by a position-dependent angle before the dot product.

Now compare every query to every key. For tokens i and j the score is s_ij = q_i · k_j, a dot product that multiplies corresponding components and adds. The score is large when the query and key point in similar directions. Collect all n^2 scores into S = Q K^T. Row i holds the scores of token i against every token j.

Softmax turns a row into shares. For row i, a_ij = exp(s_ij) divided by the sum over j' of exp(s_ij'). Take scores 2, 1 and 0. The exponentials are 7.389, 2.718 and 1.000, summing to 11.107, so the shares are 0.665, 0.245 and 0.090. With values v_1 = (1, 0), v_2 = (0, 1) and v_3 = (1, 1), the output is 0.665 v_1 + 0.245 v_2 + 0.090 v_3 = (0.755, 0.335). That is a weighted average of the values, and the weights are the softmax shares. Written out, attention(Q, K, V) = softmax(Q K^T / sqrt(d_k)) V.

The operation behaves like a differentiable lookup table. The query is a lookup key, the keys are the table's indices, the values are the table's contents. A hard table returns the value for an exact match. Attention returns a soft mixture of all values weighted by similarity. Because softmax and the dot product are differentiable, gradients reach the shares and the projections, and the table is learned end to end.

Multi-head attention runs several of these in parallel. Split d_model into h heads of width d_k = d_model / h. Each head gets its own W_Q, W_K and W_V, computes attention in its d_k-dimensional subspace, and produces an output of width d_k. Concatenate the h outputs to width d_model and multiply by an output projection W_O. The total arithmetic matches a single full-width head, but the model can run h different attention patterns at once instead of one.

The scaling factor deserves its derivation. The 2017 paper assumes the components of q and k are independent with mean zero and variance one. That is an assumption about initialization rather than a theorem. For the diagonal query-key pair, q and k come from the same token representation through different learned matrices, so they are correlated in general; for off-diagonal pairs they come from different token representations, and independence is still only an assumption. In either case the argument describes the scale at the start of training.; the argument describes the scale at the start of training. Under the assumption, each product q_a k_a has variance 1, and the sum of d_k such products has variance d_k. The score standard deviation is sqrt(d_k).

Take d_k = 64, so the standard deviation is 8. A gap of two standard deviations between the top score and the next gives an exponential ratio of e^16, about 8.9 million. Softmax hands nearly all of the mass to the top score: if that top score sits 16 above every other, with n keys and all others 16 below, its share is 1/(1+(n−1)e^−16); for a single competitor this is approximately 1 − e^−16,, and its gradient a(1 − a) is about 1e−7. Even a milder concentration is enough to stall learning. At a = 0.999 the gradient is 0.000999, while in the unsaturated example above the top share was 0.665 and its gradient was 0.665 × 0.335 = 0.223, more than two hundred times larger. The point is not the exact share but that once one key wins by a wide margin, the gradient it receives collapses toward zero and the layer stops adjusting.

Dividing the scores by sqrt(d_k) rescales the standard deviation to 1. The gap between top and next scores shrinks by a factor of 8, the exponential ratio falls from millions to single digits, and the shares stay spread out. There is a second reason to care about magnitude. In 16-bit floating point the largest representable value is 65,504, and exp overflows above about 11.1. Scores with standard deviation 8 cross that threshold routinely. Standard stable softmax implementations subtract the row maximum before exponentiating, which makes the largest exponent zero and everything else at most one, so the computation never overflows. Subtracting a constant from every score in a row leaves the shares unchanged, since the same factor cancels from numerator and denominator.

The cost is quadratic in sequence length. For each pair, the score takes d_k multiply-adds, or 2 d_k FLOPs, and the weighted sum takes another 2 d_k. Per head that is about 4 n^2 d_k FLOPs, and with d_model = h d_k it is 4 n^2 d_model per layer. Take d_model = 4096 and h = 32, so d_k = 128. The engine that motivated this book logged a mean prompt length of 130,659 tokens over 98 requests in its sampled window, derived from prompt_tokens_total divided by request count, 12,804,579 / 98. Squaring that gives about 1.71 × 10^10 pairs. Per layer the attention arithmetic is 4 × 1.71 × 10^10 × 4096, roughly 2.8 × 10^14 FLOPs, or 280 trillion. The score matrix for one head at that length holds 1.71 × 10^10 entries; in 16-bit precision that is about 34 GB, and the engine's total unified memory across weights, caches and live streams is 111.5 GB. Materializing all 32 heads at once would need over a terabyte, so real implementations tile the computation and never hold the full matrix.

Why accept the quadratic cost? A recurrent network is linear in sequence length. Each step costs O(d^2) and there are n steps, so O(n d^2). At n = 130,659 and d = 4096 that is about 2.2 × 10^12 multiply-adds per layer, against attention's 1.4 × 10^14 multiply-adds, so roughly 64 times less arithmetic. (The 2n/d ratio is 2 × 130,659 / 4096 ≈ 63.8, which is the same answer from a shorter route.) But recurrence is sequential. Step t cannot start until step t-1 finishes. Attention hands the GPU a matrix multiply, and Q K^T is one wide operation with n^2 independent dot products. Softmax is row-wise. The weighted sum is another matrix multiply. The dependency chain is short even though the total work is large. Softmax and the weighted sum still reduce over n terms, so the graph depth grows with n, but those reductions are tree-shaped and the work inside them is parallel. The trade is more arithmetic in exchange for arithmetic the hardware can actually run at once.

The 2017 paper chose the dot-product form over additive attention, which Bahdanau, Cho and Bengio introduced in 2014 for translation. Additive attention scores a pair with v^T tanh(W_1 h_j + W_2 s_i). The term W_1 h_j can be precomputed for all j, but the tanh and the final projection must be evaluated for every one of the n^2 pairs, as n^2 small matrix-vector products rather than one large matrix multiply. Dot-product attention collapses the whole score matrix into a single Q K^T. That is what makes the computation map onto hardware with thousands of cores.

Generation changes the picture. A decoder cannot let token i see tokens after it, so before softmax every score s_ij with j > i is set to negative infinity, exp becomes zero, and the row sums only over the past. The mask is a triangular array, and applying it costs almost nothing. It also means the decoder's attention is masked self-attention, distinct from the encoder's bidirectional self-attention and from cross-attention, where the decoder's queries attend to keys and values produced by the encoder.

At inference the model generates one token at a time. Recomputing keys and values for the whole prefix at every step would repeat work that has not changed, so the keys and values for positions already processed are stored in a KV cache and reused. At each decode step the model computes q_t, k_t, and v_t for the new token, appends k_t and v_t to the KV cache, and q_t attends over the cached keys and values through the current position—so t+1 entries if t tokens were already cached The cache is what makes decoding affordable, and it is also what limits concurrency. The engine here runs four streams against a shared pool of 262,144 positions, with a default reply budget of 32,768 tokens. Measured on this pair, a single stream decodes at 59.1 tok/s and four concurrent streams aggregate 106.2 tok/s, a multiplier of 1.80. The four streams contend for the same 273 GB/s of LPDDR5X memory, so the second number is well short of four times the first.

The scaling factor is the clearest case of a small numerical detail carrying a whole design. Without it the softmax saturates, the gradient for the winning share collapses toward zero, and the projections stop moving. With it, the shares stay in a range where gradients flow.

At serving time the binding constraint shifts. Prefill is compute-bound and runs at 39,237 tok/s on this engine, with 95.9% of prompt tokens served from the prefix cache, which removed 313 seconds of prefill over the sampled window. Decode is memory-bound. Each generated token reads the cache and the weights, and the streams share one bandwidth ceiling. That is where the design's cost lands once training is over.

Softmax is where attention decides

A query token scores every earlier token, then softmax turns those raw scores into shares that sum to one. Drag the temperature and watch the distribution sharpen into a single choice or flatten into noise. This is the exact reason attention stops learning when the scores get too large.
