The Shape of a Token

How a language model actually works, from the tokenizer to the sampler

A language model is a very large pile of numbers that has been arranged, through an expensive and slightly mysterious process, so that it can guess the next piece of text. Everything interesting happens in the gap between that sentence and the thing actually running on the hardware.

This book is about that gap. It starts at the character you type and ends at the token the sampler picks, and it goes through every layer in between: the tokenizer that chops your text into pieces it was trained to recognise, the embedding table that turns those pieces into coordinates, the residual stream that every layer reads from and writes to, the attention heads that decide which earlier tokens matter, the cache that remembers what has already been computed, the mixture-of-experts router that picks which parameters to load, the four-bit weights that were squeezed down from sixteen, and the sampler that turns a list of scores into one word.

Each idea in this book arrived at a particular moment to fix a particular problem, and the chapters are arranged in that order rather than in the order the code runs. Attention was invented in 2014 to stop a recurrent network from forgetting the beginning of a sentence. PagedAttention was invented in 2023 because serving systems were wasting most of their memory on padding. Grouped-query attention exists because the key-value cache outgrew the weights. Knowing what each one replaced is most of knowing what it does.

The last part grounds the whole thing on two small machines sitting on a desk, because an explanation that never touches a real number is not an explanation. But that part is the exception. Everything before it would be true on any hardware.
